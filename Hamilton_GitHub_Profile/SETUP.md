# Install your GitHub profile

1. Extract this ZIP.
2. Open your public `hrmarondedze/hrmarondedze` repository on GitHub.
3. Replace the root `README.md` with this package's `README.md`.
4. Upload the `assets` folder, keeping `assets/hero.svg` at that exact path.
5. Preview and commit the changes. The banner needs its accompanying asset; copying only the README will leave it missing.

## Before applying for jobs

- Confirm every skill listed reflects something you can demonstrate.
- Add the exact URL from your LinkedIn profile. The old link contains spaces and has not been carried over.
- Add direct links to public project repositories. Project URLs and implementation status could not be independently checked, so the profile deliberately describes them as projects under development.
- Pin three or four strong repositories. Give each a clear purpose, screenshots or a demo, setup instructions, your contribution, and current limitations.
- Keep prototypes clearly labelled. Do not describe wallet prototypes as handling real money or market analysis as proven profitable trading.

Suggested short GitHub bio:

Computer Engineering student at CUT | Building software, mobile prototypes & data tools | Exploring ML and embedded systems | Zimbabwe

## Design notes

The banner is a local SVG with no scripts, external fonts, or remote dependencies. Text content remains available below it for accessibility. Skills and contact badges use Shields.io; if that service is unavailable, their alt text still identifies them. No trophies, view counters, or externally generated statistics are required.

The included banner-preview.png is a preview of the banner only; GitHub renders the full README.
